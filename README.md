# NØVA Assets

Public static assets for the NØVA visual identity.

## Structure

- `covers/` — individual response-cover artwork.
- `icons/` — plugin and interface icons.

## CDN

After an image is committed to `main`, its jsDelivr URL follows:

```
https://cdn.jsdelivr.net/gh/Marzzz-dev/nova-assets@main/<path>
```

Example:

```
https://cdn.jsdelivr.net/gh/Marzzz-dev/nova-assets@main/covers/01-raven.webp
```

Only add approved NØVA artwork here. Keep each reference as its own separate image; do not combine the five concepts into a collage.
